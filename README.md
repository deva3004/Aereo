# Waterbody Segmentation Batch Pipeline

Batch inference pipeline that runs a pre-trained waterbody segmentation model
(`giswqs/s2-water-unetplusplus-efficientnet-b4`) over large Sentinel-2 GeoTIFFs,
producing a georeferenced water mask. Packaged as a Docker container intended for
AWS Batch-style managed batch compute.
